1 Overview

The msma package implements sparse and supervised matrix decomposition for single-block and multiblock multivariable data. The main function is msma(). The analysis is selected by the supplied inputs:

  • X only: principal component analysis (PCA);
  • X and Y: partial least squares (PLS);
  • Z: optional external supervision variable;
  • positive regularization parameters: sparse estimation.

X and Y may be matrices or lists of matrices. All blocks must contain the same observations in the same row order.

2 Simulated data

dat <- simdata(n = 40, rho = 0.8, Xps = 5, Yps = 4, seed = 1)
X <- dat$X[[1]]
Y <- dat$Y[[1]]
set.seed(1)
Z <- rbinom(nrow(X), 1, 0.5)

dim(X)
#> [1] 40  5

4 Sparse PCA

A positive lambdaX introduces sparsity into the X-side block weights.

fit_spca <- msma(X, comp = 2, lambdaX = 0.10)
fit_spca$nzwbX
#>        comp1 comp2
#> block1     5     3
fit_spca$selectXnames

#> [[1]]$comp1

5 Supervised sparse PCA

Z supplies external supervision. The strength of supervision on X is controlled by muX.

fit_sup_pca <- msma(
  X = X, Z = Z, comp = 2,
  lambdaX = 0.05, muX = 0.20,
  intseed = 1
)
fit_sup_pca$predictiv
#> [1] 0.0004154633 0.1022717687

Sparse and supervised PLS are requested by adding lambdaX, lambdaY, and optionally Z, muX, and muY.

fit_spls <- msma(
  X = X, Y = Y, Z = Z, comp = 2,
  lambdaX = 0.10, lambdaY = 0.10,
  muX = 0.10, muY = 0.10,
  intseed = 1
)
fit_spls$nzwbX
#>        comp1 comp2
#> block1     5     5
fit_spls$nzwbY
#>        comp1 comp2
#> block1     4     4

7 Prediction and low-rank reconstruction

predict.msma() projects supplied data into fitted component spaces and returns component scores and low-rank reconstructions. It does not predict Y from X. For PLS, newX and newY are reconstructed independently.

The returned elements are reconstructed X, X-side scores sbX, reconstructed Y, and Y-side scores sbY. For PCA, Y and sbY are NULL.

7.1 Historical prediction behavior

Calling predict() without Version 5 controls preserves historical behavior.

legacy_prediction <- predict(fit_pca, newX = X[1:5, , drop = FALSE])
names(legacy_prediction)
#> [1] "X"   "sbX" "Y"   "sbY"

7.2 Fitted preprocessing and reconstruction

Fitted preprocessing reuses training center and scale. Fitted reconstruction uses training-derived reconstruction coefficients.

fitted_prediction <- predict(
  fit_pca,
  newX = X[1:5, , drop = FALSE],
  preprocessing = "fitted",
  reconstruction = "fitted",
  output_scale = "original"
)
lapply(fitted_prediction$X, dim)
#> [[1]]
#> [1] 5 5
lapply(fitted_prediction$sbX, dim)
#> [[1]]
#> [1] 5 2

output_scale = "analysis" returns centered or standardized reconstructions. output_scale = "original" returns reconstructions on original variable scales. Component scores remain on the analysis scale.

7.3 PLS prediction

prediction_pls <- predict(
  fit_pls,
  newX = X[1:5, , drop = FALSE],
  newY = Y[1:5, , drop = FALSE],
  preprocessing = "fitted",
  reconstruction = "fitted",
  output_scale = "original"
)
names(prediction_pls)
#> [1] "X"   "sbX" "Y"   "sbY"

newY is not an outcome predicted from newX. The supplied newY is projected and reconstructed independently.
